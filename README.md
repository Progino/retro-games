# retro-games

A simple minesweeper game that runs in the terminal.\
It is a ricreation of the famous game Minesweeper but without graphics, in fact is 100% built in c++ and runs in the terminal.
For this the "graphic" is simply a comnìbination of letters, numbers and special characters.
For the controlls(how you choose the cell) I used a coordinates system where you have to input the x and y of the cell you want to choose.

To play it, just download the .exe file and open it in your computer.

Coding language: c++.
Made using: Visual Studio 2026.
